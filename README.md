# Динамо Москва — домашние матчи

Постоянно обновляемый календарь домашних официальных матчей ФК «Динамо» Москва (РПЛ + Кубок России) и ХК «Динамо» Москва (КХЛ). Не привязан к конкретному сезону — работает из года в год без ручных действий.

Файл обновляется ежемесячным облачным агентом:
- сначала удаляются уже прошедшие матчи;
- футбол сверяется с официальным сайтом клуба (fcdynamo.ru) и его ICS-фидом, при появлении точного времени матчей заменяет плейсхолдер-окно дат на точные дату/время (Europe/Moscow);
- хоккей сверяется с API официального сайта ХК «Динамо» (dynamo.ru/filter-games) — текущий id сезона агент каждый раз определяет сам с сайта, ничего не захардкожено — при появлении точного времени заменяет дату-плейсхолдер на точные дату/время;
- когда сезон заканчивается и начинается новый, новые матчи подтягиваются автоматически по мере публикации клубами.
