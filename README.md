# Динамо Москва — домашние матчи

Календарь домашних официальных матчей ФК «Динамо» Москва (РПЛ + Кубок России)
и ХК «Динамо» Москва (КХЛ). Не привязан к сезону: обновляется сам, из года в год.

Сыгранные матчи из календаря исчезают — это подписка, прошлое в ней не нужно.

## Подписка

Ссылка постоянная, переподписываться при смене сезона не нужно.

**Apple Calendar / iPhone:**
`webcal://raw.githubusercontent.com/sundukov17/dynamo-calendar/main/dynamo.ics`

**Google Calendar:** «Другие календари» → «Добавить по URL»:
`https://raw.githubusercontent.com/sundukov17/dynamo-calendar/main/dynamo.ics`

Календарь сам подтягивает изменения при следующей синхронизации.

## Как это устроено

`build_calendar.py` собирает `dynamo.ics` из двух источников:

- **Футбол** — официальный ICS-фид клуба `https://fcdynamo.ru/calendar/dynamo`.
  Берутся только матчи на «ВТБ Арене», товарищеские отбрасываются. Время в фиде
  московское, но без `TZID` — сборщик проставляет `Europe/Moscow` сам.
- **Хоккей** — `hockey.json` в этом репозитории. У ХК «Динамо» рабочего фида нет:
  `dynamo.ru/filter-games` отвечает 500, на `/games` отдаётся только текущий месяц,
  а `khl.ru` закрыт ботозащитой. Поэтому файл ведёт агент (см. ниже).

Раз в сутки облачный агент запускает сборщик, освежает `hockey.json` и коммитит
результат, если что-то поменялось.

### Почему в файле есть SEQUENCE

Подписной календарь у клиента обновляется только тогда, когда видит, что событие
с этим `UID` изменилось. Сборщик держит в `state.json` отпечаток каждого события и
при изменении увеличивает `SEQUENCE` — иначе Apple Calendar и Google Calendar
покажут старое время матча даже после того, как файл обновится.

### Матчи без времени

Пока лига не назначила точное время, матч лежит в календаре событием на весь день.
Как только время появляется в источнике, сборщик заменяет его на обычное событие
с началом и концом — и поднимает `SEQUENCE`, чтобы подписчики это увидели.

## Запуск вручную

```
python3 build_calendar.py
```

Скрипту нужен только стандартный Python 3.9+ (`zoneinfo`), зависимостей нет.
Файлы `dynamo.ics` и `state.json` он переписывает только при реальных изменениях.
