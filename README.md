# Динамо Москва — домашние матчи 2026/27

Календарь домашних официальных матчей ФК «Динамо» Москва (РПЛ + Кубок России) и ХК «Динамо» Москва (КХЛ) на сезон 2026/27.

Файл обновляется ежемесячным облачным агентом:
- футбол сверяется с официальным сайтом клуба (fcdynamo.ru) и его ICS-фидом, при появлении точного времени матчей заменяет плейсхолдер-окно дат на точные дату/время (Europe/Moscow);
- хоккей сверяется с API официального сайта ХК «Динамо» (dynamo.ru/filter-games), при появлении точного времени заменяет дату-плейсхолдер на точные дату/время.
