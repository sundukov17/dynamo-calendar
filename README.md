Календарь домашних официальных матчей ФК «Динамо» Москва (РПЛ + Кубок России) на сезон 2026/27.

Файл обновляется ежемесячным облачным агентом: сверяется с официальным сайтом клуба (fcdynamo.ru) и его ICS-фидом, при появлении точного времени матчей заменяет плейсхолдер-окно дат на точные дату/время (Europe/Moscow).
